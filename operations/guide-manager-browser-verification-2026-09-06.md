# 가이드 관리 실제 화면 검증과 원고 미리보기 보완

작성일: 2026-09-06 KST. 대상: `http://localhost:8788/`. [요청 경로 무결성 보완](guide-manager-route-integrity-2026-09-06.md)과 [측정·대조 관찰 연결](guide-manager-measurement-loop-2026-09-06.md)에 이어, 실제 운영 브라우저에서 편집과 검토 흐름을 확인했다. 이전 보고서의 브라우저 연결 실패는 당시 기록이며, 이번에는 연결에 성공해 직접 조작한 결과를 추가한다.

## 실제 발견과 수정

| 발견 | 사용자에게 미치는 영향 | 수정 |
|---|---|---|
| 이미 반영한 218번 출처 보강 작업에 ‘다음 할 일은 다듬기·검사’, ‘여기부터 자동 진행’이 표시됨 | 선택적으로 생략한 문장·이미지 생성을 미완료로 오해해 불필요한 재작업을 유도 | 반영 완료 원고에는 실제 완료된 승인·저장소 반영만 표시하고 다음 단계 실행을 제공하지 않는다. 명시적인 원고 재편집과 저장 후 재검사는 유지한다. |
| 기존 대표·본문 이미지를 보존했지만 미리보기에는 ‘대표 이미지 생성 대기’와 이미지 누락 | 출처만 수정할 때 보존 결과를 검토할 수 없음 | 원고에 기록된 공개 이미지 경로를 표시한다. 생성 이미지도 원고가 정확히 참조한 활성 자산만 연결한다. |
| 같은 슬롯의 예전 활성 이미지를 원고 참조보다 우선함 | 이미지 제외·교체·섹션 이동 후 미리보기와 실제 반영 결과가 달라짐 | 실제 반영 서비스와 같은 경로 일치 규칙을 사용한다. 제거된 이미지는 표시하지 않고 대소문자도 보존한다. 외부 호스트로 변하는 경로는 표시하지 않는다. |
| 파일 변경 미리보기의 X에 이름이 없고 Escape로 닫히지 않음 | 키보드 검토와 보조기술 사용에 결함 | 이름 있는 닫기 버튼, 대화상자 의미와 제목, Escape 닫기, 내부 Tab 순환, 닫은 뒤 실행 버튼으로 포커스 반환을 추가한다. 긴 파일 변경 영역도 파일명과 Tab 접근을 제공한다. |

## 운영 화면에서 확인한 범위

- 대조 글 관찰 화면에서 65번 변경 글·대조 글, 사전 선택 근거, 같은 GSC 13번·GA4 14번 원본, 플랫폼별 고정 기간, 사후 값 없음과 대기 상태가 일치했다. 기록된 상담 0과 실제 문의 여부 미확인을 구분했다.
- 218번에서 파일 변경 미리보기를 열어 실제 변경 묶음을 조회했다. 이 작업은 읽기 요청이며 저장·승인·반영을 실행하지 않았다.
- 원고 218번의 구조 JSON에 검증용 미완성 문자열을 입력하고 217번으로 이동한 뒤 218번으로 돌아왔다. 217번에는 입력이 섞이지 않았고 218번에서는 입력 문자열이 정확히 복구됐다. 서버 저장은 실행하지 않았다.
- 폐기 확인 과정에서 브라우저 연결이 지연되어 처음에는 폐기가 확인되지 않았다. 사용자도 안내가 남았다고 알려주었고, 사용자의 폐기 조작 뒤 **09:27 KST** 직접 재연결해 검증 문자열 없음·유효한 원래 JSON·미저장 안내 0개를 확인했다. 같은 시각 218번의 전체 API 응답은 검증 전과 일치했으며 `revision=7`, `status=applied`였다.

## 새 글과 검색 효과 평가

요청한 새 글은 기존 실행에서 정확히 두 개 생성·검토·배포했다. 이번 화면 보완으로 추가 생성하지 않았다.

- [루비 가열·비가열과 유리 충전 처리의 구매 전 확인 순서](https://noblessegold.com/guide/ruby-heat-treatment-buying-checklist): 작업 216, 반영 67, 기준선 63.
- [천연 지르콘과 큐빅 지르코니아 이름·재료·관리 차이](https://noblessegold.com/guide/zircon-vs-cubic-zirconia): 작업 217, 반영 68, 기준선 64.

기존 글 파일럿은 [진주 등급 보는 법](https://noblessegold.com/guide/pearl-value-factors), 작업 218·기준선 65다. 출처와 안내만 보강한 원래 변경 범위와 배포 시각을 유지한다. 이번 수정은 검토 결과의 정확성과 불필요한 제작 비용을 개선하는 기능이며, 검색 노출 상승의 직접 증거가 아니다.

GSC의 고정 사후 기간은 2026-09-06~10-03 PT, GA4는 09-07~10-04 KST 가정이다. 두 기간이 모두 끝나는 **10월 5일 00:00 KST 이후 완결 자료**가 있어야 대조 관찰을 평가할 수 있다. 기간 종료와 데이터 제공 시점은 다르다. 소량 표본·서로 다른 검색 의도·공통 사이트 변화의 영향을 남겨 두며 인과효과를 단정하지 않는다. 실제 상담·유효 문의는 실기록이 필요하고, 미기록 0건을 실제 고객 0명으로 해석하지 않는다.
