## 기능 변경과 결함 수정

- 일반 분석 자료 화면에서 페이지 URL·기간·정확 일치·전체 내보내기를 확인해 공식 ZIP을 연결할 수 있다. 사용자가 manifest 파일을 직접 만들 필요가 없다. 확인값은 별도 메타데이터이며 원본 바이트·파일명·해시를 바꾸지 않는다. 업로드 후 파일 입력을 초기화해 동일 파일도 다시 선택할 수 있다.
- 페이지 자료는 `gsc_performance_scoped`로 저장하며 사이트 전체 자료와 배포 성과 기준선을 대체하지 않는다. 속성·웹검색·기간·정확한 URL이 맞아야 해당 글에 연결한다. URL의 대소문자·끝 슬래시·쿼리를 임의로 정규화해 서로 다른 필터를 합치지 않는다.
- 일별·페이지·검색어 표의 전체 행, 클릭·노출·CTR·순위와 합계 무결성을 검사한다. 노출 0인 실제 내보내기의 비어 있는 마지막 CTR·순위 값은 허용하되 누락된 클릭·노출을 만들어내지 않는다. 불완전한 범위나 다른 필터는 사용자 확인으로 덮어쓸 수 없다.
- 같은 파일을 다시 가져와도 동일 ID를 유지하고 행을 중복 추가하지 않는다. 구형 자료의 명시적 재검증을 지원하며, 확인 일시와 원본·검색어 행을 포함한 자료 지문을 남긴다. 전수 진단의 페이지 검색어 수집은 DB 조회 두 번으로 처리한다.
- 정확한 페이지 자료와 사이트 전체 참고 검색어를 분리했다. 공개된 검색어 행 수, 정확한 URL의 실적, 검색어 표 합계를 별도로 표시한다. 표시행 0을 수요 0으로 해석하거나 전체 사이트 검색어를 해당 글의 검색어로 승격하지 않는다.
- 제목 검토 후보는 내용 관련성, 측정 종료 후 7일 이내, 20회 이상 노출 또는 3회 이상 클릭으로 선별한다. 이는 앱의 검토 우선순위 기준이며 Google 기준이나 통계적 유의성 판정이 아니다. 후보가 있어도 수정 항목은 기본 해제 상태다.
- 실제 검색어 선택, 원문에서 확인한 불일치 기록, 검토 확인, 직접 입력한 제목·설명이 있어야 수동 교정안을 만든다. 같은 문구는 작업을 생성하지 않는다. 이 항목은 제목·설명만 다루는 별도 작업이며 본문·출처·이미지를 보존한다.
- 사용자가 쓴 제목을 다시 AI에게 작성시키지 않고 검토 초안으로 바로 연다. 검수·변경 비교·승인으로 진행한다. 기존 자동 준비·조사 경로로 불필요한 유료 호출이 발생하는 진입점도 제한한다.
- 생성·저장·승인·반영 단계에서 현재 원문과 페이지 검색어의 URL·기간·수입 ID·자료 지문을 다시 검증한다. 자료를 교체하거나 같은 ID의 행을 바꾼 경우도 검토를 다시 받아야 한다. D+31·기존 성과 제목·커스텀 글 보호는 유지한다.

## 효과의 판단 범위

이번 변경으로 실제 페이지 검색어가 업로드에서 진단과 수정 초안까지 연결된다. 불필요한 재작성과 비용을 줄이고, 확인한 문제만 원문에 반영하도록 기능을 고친 것이다. 자동 추천 수나 검사 통과 수를 검색 노출 상승으로 계산하지 않는다.

이미 게시한 [루비 가열·비가열 구매 가이드](https://noblessegold.com/guide/ruby-heat-treatment-buying-checklist)와 [지르콘·큐빅 지르코니아 비교](https://noblessegold.com/guide/zircon-vs-cubic-zirconia) 두 편의 배포 기준선을 유지한다. 현재 원본 기간은 두 글의 배포 전이므로 이번 글들의 사후 효과를 증명하지 않는다. 실제 노출·클릭·상담 결과는 후속 동일 기간 자료로 확인해야 한다.
