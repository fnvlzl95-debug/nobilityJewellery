# 귀족 가이드 관리: 신규 작성·기존 수정 고도화와 검증

점검·작업일: 2026-09-06 KST

대상: `http://localhost:8788/`, `tools/guide-manager`, 연동된 `noblessegold.com` 가이드

## 판단과 범위

이번 변경은 글을 많이 만드는 것보다 **중복 작업과 근거 없는 자동 판단을 줄이고, 선택한 수정 범위를 실제 파일까지 지키는 것**에 집중했다. 검색 자료가 부족하면 자동 추천을 멈추고 편집 선정 사유를 기록한다. 새 글과 기존 글의 성과 측정 방식도 구분한다.

글 선택 경합 회귀 시험을 포함한 최종 관리 도구 테스트 114개가 모두 통과했다. 일반 가이드 103개의 출처 수정 결과도 파일 파싱과 본문 보존을 확인했다. 새 글 2편은 실제 관리 도구로 생성하고 공식 자료·내부 링크를 대조한 뒤 사이트에 반영했다. 최종 TypeScript·빌드·SEO 검사, 로컬 관리 도구 배포, 코드 커밋·원격 푸시와 공개 사이트 배포를 완료했다. 공개 URL에서 두 글과 이미지의 정상 응답, 구조화 데이터와 생성 이미지 안내도 확인했다. 이는 기능·정책·원고·배포 검증 결과다. 검색 순위나 상담 증가를 확인한 결과는 아니다.

이 문서는 로컬 보고서 `outputs/귀족_새글작성_기존글수정_실효성_정밀분석_2026-09-06.md`의 후속 작업 기록이다. 이전 보안·반영 복구·사이트 연동 개선은 [기존 점검 기록](guide-manager-audit-2026-09-06.md)에 남겼다. 이번 회귀 시험은 이전 75개 테스트가 다루지 못한 품질 문제를 추가로 검증한다.
