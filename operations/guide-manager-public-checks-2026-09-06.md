# 가이드 관리 공개 상태 점검 보완

작성일: 2026-09-06 KST. 대상: `http://localhost:8788/`의 반영 이력과 `https://noblessegold.com`의 공개 가이드. [직전 브라우저 검증](guide-manager-browser-verification-2026-09-06.md)에 이어 배포 후 확인 단계를 보완했다.

## 발견한 공백과 실제 개선

기존 배포일 기록은 날짜 형식·순서와 커밋 문자열 형식을 검사하지만, 그 시각의 실제 배포나 현재 공개 응답을 증명하지 않는다. 로컬 SEO 검사를 통과해도 공개 주소가 정상인지, 검색을 차단하는 설정이 있는지는 관리 화면에서 별도로 확인할 수 없었다. 과거 배포일을 현재 HTTP 요청으로 입증할 수도 없으므로, 기존 기록과 별개의 **현재 공개 상태** 기능을 추가했다.

반영 이력의 해당 글에서 `공개 상태 확인`을 누르면 다음 7항목을 저장한다.

| 항목 | 확인 범위 |
|---|---|
| HTTP | 정확한 공개 주소가 200을 반환하는지. 리디렉션은 따라가지 않는다. |
| HTML | Content-Type이 text/html인지. |
| 제목 | 현재 저장소 원고 제목과 공개 HTML의 단일 H1이 일치하는지. 본문 전체 비교는 아니다. |
| canonical | head에 자기 공개 URL을 가리키는 canonical이 하나인지. HTTP Link canonical 충돌도 확인한다. |
| 색인 차단 지시 | robots/googlebot 메타와 X-Robots-Tag의 noindex·none. 적용 범위가 모호하면 미확인으로 남긴다. |
| robots.txt | 해당 URL에 대한 Googlebot 접근 허용 여부. |
| 사이트맵 | 현재 sitemap.xml의 단일 urlset에 정확한 공개 URL이 수록됐는지. 인덱스 사이트맵은 자동 추적하지 않는다. |

색인 차단 지시는 [Google의 robots 메타·X-Robots-Tag 설명](https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag)을 기준으로 처리한다. robots.txt 접근 판정과 검색 색인은 다른 문제다. [Google robots.txt 규칙](https://developers.google.com/crawling/docs/robots-txt/robots-txt-spec)에 따라 이 둘을 구분하며, 사이트맵 수록도 색인·순위 보장이 아니다. [Google 사이트맵 설명](https://developers.google.com/search/docs/crawling-indexing/sitemaps/overview).

## 병목·오판 방지

- 목록은 저장 결과를 한 번 조회한다. 글별 외부 요청은 버튼으로 실행하며, 목록 새로고침이나 카드 렌더링으로 재점검하지 않는다.
- 같은 글의 동시 요청은 합치고 서로 다른 글은 최대 3건까지 허용한다. 요청마다 본문 읽기까지 8초, HTML·사이트맵 각각 3MiB, robots.txt 500KiB로 제한한다. 한 글은 3개 응답을 순서대로 확인하므로 모두 지연되면 약 24초가 걸릴 수 있다.
- 등록된 가이드의 고정 HTTPS 도메인만 요청한다. 임의 URL·리디렉션 대상·외부 XML 엔터티는 처리하지 않는다.
- 연결 실패·지원하지 않는 형식·모호한 차단 지시를 통과로 처리하지 않는다. 값이 없는 상태와 점검 실패를 구분한다.
- 점검 시각과 원고 SHA-256을 저장한다. 조회 시 원고가 달라졌거나 24시간이 지났으면 재확인 대상으로 표시한다. 점검 도중 원고가 바뀐 경우도 마지막에 다시 확인한다.
- 늦게 도착한 목록 응답이 버튼으로 실행한 새 결과를 덮어쓰지 못하게 한다. 실패·진행 중·오래된 기록은 이전 성공 결과를 현재 통과로 표시하지 않는다.
- 새 `public_page_checks` 테이블에만 점검 스냅샷을 쌓는다. 원고·반영 이력·배포일·관찰 기준선을 변경하지 않는다.

## 검색 효과 판단의 범위

이 기능의 실익은 공개 주소의 오류, 제목 불일치, 검색 차단과 사이트맵 누락을 작성·수정 뒤 같은 관리 화면에서 발견할 수 있다는 점이다. Google의 실제 색인 상태, 전체 본문·구조화 데이터 일치, 과거 커밋 배포 시각이나 검색 노출 상승을 증명하는 기능은 아니다. 확인 후 공개 사이트 설정이 달라질 수 있으며 저장 결과는 그 확인 시점의 기록이다.

이미 배포한 새 글은 정확히 두 개다: [루비 처리 구매 체크리스트](https://noblessegold.com/guide/ruby-heat-treatment-buying-checklist), [지르콘과 큐빅 지르코니아](https://noblessegold.com/guide/zircon-vs-cubic-zirconia). 기존 글 [진주 등급 보는 법](https://noblessegold.com/guide/pearl-value-factors)의 출처 보강 파일럿과 대조 글도 원래 상태를 유지한다.

실제 효과는 원래 배포일부터 고정한 GSC 2026-09-06~10-03 PT, GA4 09-07~10-04 KST 가정의 사후 자료와 실제 문의 기록으로 평가한다. 두 기간이 끝나는 **10월 5일 00:00 KST 이후 완결 자료**가 필요하며, 데이터 제공이 더 늦을 수 있다. 현재의 기술 점검 통과를 노출 증가로 바꾸어 보고하지 않는다. 대조 관찰도 낮은 표본, 서로 다른 검색 의도와 사이트 공통 변화의 영향을 받으므로 인과효과를 단정하지 않는다.
