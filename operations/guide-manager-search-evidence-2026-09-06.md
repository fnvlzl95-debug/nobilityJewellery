## 발견한 결함과 수정

| 결함 | 수정과 효과 |
|---|---|
| GSC 필터를 무시해 특정 페이지·기기 등 부분 자료가 사이트 전체 추천에 사용될 수 있음 | 속성·웹검색 여부·활성 필터·기간·전체 행 수를 검증한다. 범위 제한·미확인 자료는 `gsc_performance_scoped`로 보관하고 전체 추천·배포 비교에서 제외한다. |
| 기존 파서 자료를 새 정책에서도 무조건 신뢰 | 범위 메타가 없는 기존 원본은 미검증으로 안내한다. 명시적 재업로드 시 같은 ID와 원본을 유지하며 메타와 행을 트랜잭션으로 재검증한다. 기존 기준선 스냅샷은 변경하지 않는다. |
| 빈 클릭·노출·CTR을 0으로 바꿔 성과를 만들어냄 | 누락은 `null`로 보존하고, 비정상 날짜·수치·중복 행·선언과 다른 행 수를 거부한다. |
| 나중에 업로드한 과거 보고서가 배포 이후 비교 자료를 밀어냄 | 적격 보고서 중 측정 종료일이 가장 최신인 자료를 선택한다. 같은 기간은 가져온 시각과 ID로 정한다. |
| 변경 후 자료만 검증하고 미검증된 변경 전 GSC 기준선과 비교 | 변경 전 원본의 속성·범위와 스냅샷의 기간 일치도 확인한다. 문제가 있으면 GSC 증감 계산을 보류하고 사유를 표시한다. 같은 원본을 명시 재업로드해 검증해도 기존 스냅샷은 보존한다. |
| 연결할 클러스터를 자동 선택하지 못해도 신규 글 반영이 계속됨 | 실제 기존 페이지에서 새 글로 연결되는 경로를 확인하고 승인·반영에 연결한다. 관련 묶음 선택을 수정할 수 있게 하며, 연결이 없거나 잘못된 선택이면 게시 전 해결하도록 한다. |
| GA4 비교 파일의 첫 블록을 최신 기간으로 간주 | 유효한 최신 기간을 명시적으로 고르고 해당 기간의 블록만 집계한다. 비교 기간은 별도 메타로 보존한다. |
| GA4 제목 변경으로 연결에서 빠진 조회가 화면에 드러나지 않음 | 제목 일치 연결의 한계와 연결·미연결 행 수, 대표 누락 제목을 표시한다. 비슷한 제목을 임의로 합치지 않는다. |
| GA4 여러 페이지의 사용자를 더하거나 평균 참여 시간 누락을 0초로 표시 | 전체 고유 사용자 합계를 만들지 않고, 미확인 값과 실제 0을 구분한다. 과거 organic 자료의 합산 사용자 값도 분석 자료 화면에서 전체 사용자로 표시하지 않는다. |
| 카테고리 목록의 CollectionPage URL·설명·H1이 전체 목록으로 고정 | 카테고리의 기존 설명과 실제 canonical을 H1·검색 설명·OG·Twitter·구조화 데이터에 연결한다. 전체 목록 기본 문구, 검색·후속 페이지의 noindex 정책은 유지한다. JSON-LD의 `<`를 이스케이프한다. |

## GA4 해석 범위

확보된 새 개요 자료는 8월 8일~9월 4일이며 전체 활성 사용자 1,478명·이벤트 9,981회, 페이지 제목 227행이다. 이전 최신 자료의 종료일은 8월 22일이었다. 제목이 바뀐 글의 과거 제목 행은 경로 증거 없이 합칠 수 없다. 예를 들어 금 1돈 글은 현제목 48조회와 과거 제목 60조회로 나뉜다.

전체 채널 방문 페이지 CSV를 Google 자연 검색 보고서로 받아들이지 않는다. 세션을 조회수로, 세션당 시간을 사용자당 시간으로 저장하지 않는다. 기기·페이지 사용자 합산, 주요 이벤트 수를 세션 수로 나눈 전환율 재계산도 하지 않는다. 지원하지 않는 CSV 유형에는 해당 이유와 필요한 형식을 안내한다.

## 효과를 판단할 조건

새 글은 배포 전 성과 0과 비교하지 않는다. 기존에 기록한 두 신규 기준선의 배포 시각과 커밋을 유지하고, 배포 이후 충분한 기간의 실제 GSC 자료가 들어오면 발견·클릭을 관찰한다. 현재 9월 3일까지의 검색 자료로 9월 6일 발행의 성과를 평가할 수 없다. 상담·계약은 실제로 확인한 기록과 버튼 클릭을 구분한다.

내용의 유용성, 독자가 찾을 수 있는 연결, 데이터의 정확성은 지금 검증할 수 있다. 순위·노출·상담의 증가는 이후 관측 자료가 필요하다. [Google의 유용한 콘텐츠 안내](https://developers.google.com/search/docs/fundamentals/creating-helpful-content), [검색 기본 안내](https://developers.google.com/search/docs/fundamentals/seo-starter-guide)를 판단 근거로 삼았다.
