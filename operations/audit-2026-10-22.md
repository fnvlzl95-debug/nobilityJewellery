# 2026-10-22 감사 개선 작업 기록

이 문서는 SEO·서비스 콘텐츠 담당 변경 기록이다. 통합 빌드, UI·계측 검증과 운영 배포 결과는 최종 검증 후 별도로 추가한다.

## 이미지 사이트맵

- 감사에서 XML 이미지 항목 576개 중 325개에 이중 이스케이프가 있었다. 표준 XML 파싱 뒤 URL에 `&amp;`가 남았고, 해당 고유 URL 312개는 404였다. 정상 URL 312개는 200으로 확인했다.
- Nuxt Sitemap의 HTML 이미지 자동 수집 결과에서 IPX modifier의 HTML 엔터티가 남는 경로를 확인했다. `server/plugins/sitemap-images.ts`의 `sitemap:resolved` 훅에서 해당 부분만 URL 값으로 되돌린다. XML 직렬화는 모듈에 맡긴다. 이미지 파일명과 다른 URL의 엔터티·퍼센트 인코딩은 변경하지 않는다.
- 설치된 sitemap 모듈의 실제 직렬화 코드와 XML 파서를 사용한 회귀 검사 4개 통과. 정상 동작, 수정 전 실패 재현, 원본·정상 URL 보존, 잘못된 XML 거부를 확인했다.
- `verify-seo-output.mjs`에 사이트맵 XML 파싱, 모든 내부 이미지 실파일 존재, BreadcrumbList 최소 2항목 검사를 추가했다. 홈 1항목 breadcrumb 제거는 UX 담당 변경에 포함된다.
- 근거: [Nuxt Sitemap Nitro hooks](https://nuxtseo.com/docs/sitemap/nitro-api/nitro-hooks), [Google 이미지 사이트맵](https://developers.google.com/search/docs/crawling-indexing/sitemaps/image-sitemaps), [Google breadcrumb](https://developers.google.com/search/docs/appearance/structured-data/breadcrumb).

## 서비스 페이지

- `/custom`, `/repair`, `/baby-gold`, `/wedding`, `/buy-gold`의 title·description·OG·Twitter 정보를 같은 페이지 기준으로 정리했다. 실제 준비자료·상담 조건을 설명하고 사용하지 않는 meta keywords를 제거했다.
- 주문제작의 `1–2주`를 운영 문서의 `최소 2주, 최종 사양 확인 후 일정 안내`로 정리했다. 수리의 모든 작업 가능·최대 2호 단정은 소재·구조·상태 확인 기준으로 바꿨다. 확정하지 않은 띠별 제작 가능 범위도 상담 조건으로 표현했다.
- `ServiceQuestions.vue`와 `data/service-questions.ts`로 고객의 실제 질문, 확인할 자료, 공개 제품·가이드 링크를 연결했다. 금·은 매입 페이지는 기존 질문 영역에 시세와 최종 지급액의 차이를 보강했다. 새 FAQ 리치결과 노출을 약속하거나 임의 가격·중량·리뷰를 만들지 않았다.
- 말띠 제품은 기존 `/gallery/pure-gold-horse-baby-ring`을 활용한다. 별도 중복 `/horse` 페이지를 만들지 않았다.
- 기준 자료: `PRODUCT.md`, `config/site.ts`, `data/gallery-items.ts`, 이미 공개된 관련 가이드. 실재 확인되지 않은 고객 사례·공정 사진은 추가하지 않았다.
- 납기 최종 대조에서 갤러리 원본 데이터의 과거 `1–2주` 33개를 공통값으로 정리했다. 기존 export도 이미 `최소 2주`로 덮어쓰고 있었으므로 운영 42페이지가 잘못된 기간을 표시했다고 단정하지 않는다. 이제 표시는 `최소 2주 · 상담 후 확정`, 상세 메타는 자연스러운 문장으로 안내한다. 말띠 아기 돌반지의 잘못된 영어명 `Signet Ring`을 `Horse Motif Baby Ring`으로 바꿨다. 도매 페이지의 `재고: 당일 / 주문제작: 1–2주`는 재고 확인·최소 2주·상담 후 일정 확정으로 수정했다. 커플링 페이지는 이미 최소 2주였으며, 전체 페이지·데이터에서 단정적인 1–2주 제작 문구를 다시 검색했다.

## 의존성 보안 후속

추가한 XML 파서와 sitemap 런타임의 `fast-xml-parser`를 취약한 5.3.3에서 같은 major의 5.11.2로 교체했다. XML 회귀 4개와 전체 타입 검사 통과. 전체 npm audit은 57→56개(critical 6→5), omit-dev는 54→53개다. 잔여 critical 5개는 현재 production worker 소스맵에 포함되지 않는 개발·설치·빌드 체인이다. DevTools는 `enabled: false`로 개발 환경에서도 비활성화하는 공식 완화책을 적용했다(production 평가값은 변경 전후 동일). Worker에 포함되는 Nuxt/h3/Vue 등의 기능 조건, 실제 코드 대조와 한계, 이후 호환 업데이트 단위는 [의존성 보안 감사](dependency-audit-2026-10-22.md)에 기록했다. 전체 취약점 수정 완료로 표시하지 않는다.
