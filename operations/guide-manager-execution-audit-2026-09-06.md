# 검색 개선 계획의 실제 실행 경로 검증

대상: `http://localhost:8788/`의 기존 글 진단·수정 계획·원고 생성. [검색 원본·공개 연결 후속 검증](guide-manager-search-evidence-2026-09-06.md)에 이어, 진단이 실제로 유효한 수정으로 이어지는지 확인했다.

## 배포 전 운영 자료에서 확인한 결함

현재 운영 API에서 가이드 107개와 각 글의 저장된 수정 계획을 모두 읽었다. 검색 자료는 앞선 기록과 같은 GSC 8월 7일~9월 3일, GA4 개요 8월 8일~9월 4일이다. 원고 생성이나 유료 AI 호출을 실행해 수집한 자료가 아니다.

| 결함 | 실제 근거 | 필요한 동작 |
|---|---|---|
| 관찰 계획이 본문 수정으로 실행됨 | 37개 계획에 활성 `preserve-and-monitor` 항목. `jongno-wedding-jewelry-consultation-checklist`는 관찰 보호 기간도 지나 실행 가능한 상태였다. | 관찰은 원문을 변경하지 않아야 한다. 오래된 저장 계획도 생성 요청 단계에서 차단해야 한다. |
| 출처 보존 지시가 새 출처 추가도 막음 | `출처 백필` 분류 32개와 복합 수정 계획을 합쳐 43개에 `add-official-evidence`가 활성화돼 있었다. `출처 URL` 보존 문구가 `sources` 전체 필드 잠금으로 해석됐다. | 기존 출처 항목은 유지하고 검증한 새 출처만 추가해야 한다. 출처 목록 전체를 명시적으로 보존하는 지시는 계속 잠가야 한다. |
| 전체 사이트 검색어가 특정 글의 제목 수정 근거가 됨 | `wedding-ring-production-time`은 페이지 노출 122회. 사이트 전체에서 1회 노출된 `보석`을 유사도 0.85로 선택해 제목 앞 20자에 넣도록 제안했다. 같은 자동 제목 수정 항목은 35개 계획에 있었다. | 페이지·검색어가 함께 측정된 근거와 사이트 전체 참고 검색어를 구분해야 한다. 후자로 특정 페이지의 검색어를 단정하거나 자동 제목 수정을 만들면 안 된다. |
| 낮은 노출을 내부 링크 부족으로 단정 | `내부링크 강화` 30개 중 27개는 유입 링크가 이미 2개 이상, 30개 모두 관련 링크가 3개 이상이었다. | 실제 연결 누락이 있을 때만 보완해야 한다. 발신 링크를 늘리는 작업으로 다른 글에서 들어오는 링크 부족을 해결했다고 표시하면 안 된다. |
| 적은 방문 수로 본문 결함을 판정 | `necklace-breakage-meaning-and-causes`는 본문 구조 점수 100, 공식 출처 4개인데 GA4 조회 7회·이탈률 85.7%로 본문 보강 분류였다. | 이탈률만으로 본문 재작성을 권하지 않아야 한다. 적은 표본은 관찰 근거로 남기고 원문에서 확인한 결함과 구분해야 한다. |

이 수치는 분류와 실행 계획을 구분한다. 예를 들어 출처 백필 분류는 32개지만, 다른 분류의 복합 수정 계획까지 포함한 출처 추가 항목은 43개다. 관찰 보호·보호 페이지 등 기존 서버 제한이 별도로 있어, 활성 항목 수가 곧 즉시 실행 가능한 글 수는 아니다.

전후 원본은 로컬 `.tmp/search-execution-2026-09-06/`에 보관한다. 운영 DB와 검색 원본 전체는 Git에 포함하지 않는다.

## 수정 결과

- 관찰은 별도 안내로 옮겼다. 수정할 항목이 없는 계획은 작업을 생성하지 않으며, 기본 일괄 유료 정밀진단에서도 제외한다. 사용자가 특정 글의 추가 정밀진단을 명시적으로 실행하는 경로는 유지한다.
- 출처 URL 보존은 기존 항목의 URL·표시명·설명·순서를 고정하고 새 URL만 추가한다. 선택하지 않았거나 확인한 주장과 연결되지 않은 출처는 계속 거부한다. 명시적으로 출처 목록 전체를 잠근 계획은 계속 잠근다. 이미 생성한 편집 작업의 동결된 수정 범위는 자동 확장하지 않는다.
- 사이트 전체 검색어는 참고 필드로 분리하고 특정 페이지의 검색어 수는 `null`로 표시한다. 무관한 일반어·작은 참고 신호는 제외하며 유사도를 페이지 연결 확률처럼 표시하지 않는다. 근거 없는 자동 제목 수정은 비활성화하고 화면에서 재선택할 수 없게 했다. 기존 수동 제목 수정은 원문과 별도 확인한 근거를 바탕으로 사용할 수 있으며 D+31·성과 제목 보호를 유지한다.
- 낮은 노출이나 이탈률만으로 링크·본문 결함을 만들지 않는다. 유입 링크가 적은 글은 기존 글·공유 묶음 연결을 검토하도록 안내하며, 그 글의 발신 링크를 늘리는 자동 편집과 구분한다.
- 자연 검색의 고유 사용자 합계 미확인값을 `null명`으로 표시하던 문구와 평균 참여 시간 누락을 0초로 표시하던 화면을 고쳤다.
- 진단 항목 ID만 확인하던 직접 생성 경계를 보완했다. 항목 ID를 변경·생략한 관찰 및 사이트 전체 검색어 제목 계획도 내용으로 판별해 생성·저장·승인·반영 전에 차단한다. 임시 HTTP 서버에서 유효한 audit ID를 사용한 실제 생성 요청과 캐시된 구형 작업의 후속 실행을 함께 검증했다.

검색어 근거는 [Search Console 실적 보고서의 집계 차원](https://support.google.com/webmasters/answer/7576553?hl=en)을 구분하고, 제목 수정은 [Google 제목 링크 안내](https://developers.google.com/search/docs/appearance/title-link)에 따라 실제 본문을 구체적으로 설명하는지를 확인한다.

## 운영 전후 비교

같은 원고·같은 검색 자료로 107개를 다시 스캔했다. 새로운 유료 AI 전수 분석을 실행한 결과가 아니다.

| 항목 | 변경 전 | 변경 후 |
|---|---:|---:|
| 내부 링크 검토 분류 | 30 | 3 |
| 본문 보강 분류 | 1 | 0 |
| 유지 분류 | 9 | 37 |
| CTR 검토 분류 | 35 | 35 |
| 출처 백필 분류 | 32 | 32 |
| 활성 관찰·본문 작성 항목 | 37 | 0 |
| 활성 자동 CTR 제목 작성 항목 | 35 | 0 |
| 활성 출처 추가 계획 | 43 | 43 |
| 활성 편집 항목이 없는 계획 | 0 | 63 |

이는 낮은 CTR 신호 자체를 숨긴 것이 아니다. 제목 수정에 필요한 근거가 없다는 점을 실행에 반영했다. 남은 내부 링크 검토 3개는 유입 링크가 각각 1개인 `mother-necklace-production-time`, `yellow-gold-ring-discoloration-causes`, `earring-closure-selection-guide`다. 세 글 모두 관련 링크는 3개이며 현재 D+31 관찰 중이다. 순위 문제로 단정하거나 자동으로 본문을 고치지 않는다.

출처 보강 43개는 운영에서 읽은 계획과 새 범위 해석을 연결해 `sources` 허용·기존 URL 보존을 모두 확인했다. 별도 격리 검증에서는 출처 백필 32개 원안과 복합 계획의 출처 범위 43개에서 실제 공개 출처 템플릿의 링크 출력까지 확인했다. 복합 원안 11개에 섞였던 자동 CTR 항목은 별도로 차단하고 출처 부분을 검증했다. 외부 유료 호출과 운영 글 변경은 없었다.

현재 앱은 페이지로 필터한 GSC 자료를 특정 글의 검색어 근거로 자동 연결하지 않는다. 이를 지원하는 것처럼 안내하지 않으며, Search Console에서 해당 URL·기간·검색어를 사람이 확인한 뒤 `가이드 편집 → 기존 글 수정 → 검색 제목·설명`에서 원문과 대조할 수 있음을 표시한다. 업로드만으로 성과·관찰 보호가 해제되지는 않는다.

브라우저의 localhost 탭은 연결 시간 초과 또는 `ERR_BLOCKED_BY_CLIENT`, Windows 화면 제어는 native pipe 연결 불가였다. 따라서 실제 운영 화면의 최종 마우스·키보드 조작 검증은 미완료이며, 빌드·API·격리 회귀 결과와 구분한다.

이번 커밋은 관리자 소스·회귀 시험·사용 안내·이 보고서만 포함한다. 공개 사이트는 앞선 `1f5f4cc6264afa5af39982e9c00cf6d4563169d1` 배포([6f29f45c.nobilityjewellery.pages.dev](https://6f29f45c.nobilityjewellery.pages.dev))를 유지한다. 이미 공개된 [루비 가열·비가열 구매 가이드](https://noblessegold.com/guide/ruby-heat-treatment-buying-checklist)와 [지르콘·큐빅 지르코니아 비교](https://noblessegold.com/guide/zircon-vs-cubic-zirconia)의 게시·색인 요청 기록은 앞선 보고서에 있다.

## 효과의 범위

이번 개선은 근거 없는 재작성과 비용을 줄이고, 확인한 출처를 실제 원문에 반영할 수 있도록 실행 결함을 고치는 작업이다. 테스트 통과를 Google 노출·순위 상승으로 환산하지 않는다. 이미 게시한 루비·지르콘 글 2편의 배포 기준선과 측정 대기 상태를 유지한다. 공개 글을 추가로 생성하거나 107개를 일괄 재작성하지 않는다.
