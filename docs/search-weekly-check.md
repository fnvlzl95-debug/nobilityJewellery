# 주간 검색 성과 점검

매주 같은 요일에 Google Search Console에서 최근 28일의 **검색 결과 → 페이지** 데이터를 ZIP 또는 CSV로 내보냅니다. 비교 조건은 검색 유형, 국가, 기기를 전주와 동일하게 유지합니다.

## 자동 점검

프로젝트 루트에서 내보낸 ZIP을 그대로 지정합니다.

```powershell
npm run audit:ctr -- "C:\경로\Performance-on-Search.zip"
```

압축을 푼 `페이지.csv`도 같은 방식으로 사용할 수 있습니다.

```powershell
npm run audit:ctr -- "C:\경로\페이지.csv"
```

기본 기준은 **노출 100회 이상, CTR 1% 미만**입니다. 스크립트는 슬래시 URL과 무슬래시 URL을 하나로 합친 후 클릭·노출·평균순위를 다시 계산합니다.

필요하면 기준과 출력 형식을 바꿀 수 있습니다.

```powershell
npm run audit:ctr -- "C:\경로\페이지.csv" --min-impressions=200 --max-ctr=1.5 --format=markdown
```

## 검토 순서

1. 후보 URL의 대표 검색어와 평균순위 변화를 확인합니다.
2. 순위가 유지되는데 CTR만 낮으면 제목과 메타 설명의 검색 의도 일치 여부를 봅니다.
3. 제목을 바꿀 때는 한 URL당 한 가지 가설만 기록합니다.
4. 변경일, 이전 제목, 새 제목, 기준 지표를 `docs/search-title-tests-YYYY-MM-DD.md`에 남깁니다.
5. 4주 뒤 같은 28일 조건으로 비교합니다. 노출 100회 미만은 판정을 미룹니다.
6. 평균순위가 2계단 이상 달라졌다면 CTR 변화만으로 제목을 성공·실패 판정하지 않습니다.

## 주간 운영 체크

- 사이트맵 URL 수와 오류 상태 확인
- 무슬래시 대표 URL이 200, 슬래시 변형이 1회 308인지 표본 확인
- `generate_lead` 접수 ID와 실제 문의 메일 대조
- 검색 후보 중 사업 의도가 높은 페이지를 우선 검토
- 새 가이드는 관련 클러스터 데이터(`data/guide-clusters.ts`)에 연결
- 외부 사실을 인용한 가이드는 공식 출처 링크와 최종 검토일 갱신
